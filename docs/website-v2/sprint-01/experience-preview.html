The problem

Orders don't arrive in one place.

  1. An order is a chat message, then a note, then a row someone re-types.
  2. Payment confirmation lives in a different thread from the order.
  3. Exceptions — a missing address, a changed quantity — have no owner.
  4. Nobody can answer "what is waiting right now?" without asking around.

How it is shaped

One record per order. Every change on the record.

Every order becomes one canonical record. Each change to it is recorded as an event, scoped to the business it belongs to. Orders that need a person surface in one queue.
