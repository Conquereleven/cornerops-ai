# OpenClaw Roadmap

## MVP

- Dry-run gateway client.
- Channel router mocks.
- Tool policies.
- Human approval backend.
- Audit logs.

## Internal Beta

- Persist approvals and audit logs.
- Operator UI for approvals.
- Slack sandbox channel.
- GitHub issue draft flow.

## Limited Production

- WhatsApp/Telegram allowlists.
- HMAC/signature verification per channel.
- Approved send flows.
- Alerting for gateway failures.

## Future

- Multi-agent routing.
- OpenClaw plugin catalog evaluation.
- Persistent memory bridge with clear ownership.
- Advanced analytics for latency, policy decisions and approvals.
