# Authorized Seller Data Boundary v1.13

All persistence is in `cornerops_internal`. Public, anon, authenticated and service-role access is revoked. Runtime receives only required select/insert and narrowly controlled updates. Ledger, media, application, catalog-package and coverage records are append-only. Hostile source text is sanitized bounded data and cannot alter rules or invoke tools.

No supplier/customer contact, quote generation, purchase, product activation, WhatsApp, email, OpenClaw or CornerMex write is enabled.
